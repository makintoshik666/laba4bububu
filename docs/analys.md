# Краткий анализ проекта

Проект InteractiveCoinSystem — демонстрационный платформер на Unreal Engine 5.8. Игровая логика реализована в Blueprint, основной уровень — `ExampleLevel`.

На уровне есть персонаж, обычные и движущиеся платформы, прыжковые площадки, блоки с монетами и испытания со сбором монет. Монеты размещены как отдельными объектами, так и группами вдоль сплайнов. Общий счётчик монет хранится в `Game_Instance_BP`; кристаллы учитываются отдельно.

Сильная сторона проекта — готовые механики сбора и разнообразные препятствия. Отдельные Blueprint позволяют добавлять новые объекты с использованием существующего счётчика. Ресурсы разделены по назначению: логика, карты, интерфейс, звук и визуальные эффекты.

На маршруте нет ворот, которые требуют определённое количество монет для прохода. Планируется добавить такую механику на переходах между участками уровня. Для этого можно создать отдельный Blueprint ворот с настраиваемым порогом открытия и проверкой существующего счётчика монет. Это даст игроку дополнительную цель при сборе монет.
